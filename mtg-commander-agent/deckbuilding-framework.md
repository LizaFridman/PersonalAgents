# Deck-Building Framework

> Upload this file as Project knowledge. It's a working structure for deck-building conversations, not a rules document (see `commander-rules-reference.md` for that). Use it to keep deck discussions consistent and to make card cuts/includes defensible rather than vibes-based.

## Step 1 — Anchor the deck before picking cards

Before recommending cards, establish (and record in the deck's `wiki/<topic>.md` page — see `wiki-structure.md`):

1. **Commander and color identity.**
2. **Archetype / game plan** — what the deck is actually trying to do. Pick one primary plan; a deck trying to do three unrelated things is usually worse than one doing one thing well. Common Commander archetypes: aristocrats (sacrifice value), voltron (single-creature beatdown via auras/equipment), group hug/politics, stax (resource denial), tokens/go-wide, spellslinger, reanimator, ramp-into-big-stuff, tribal synergy, combo.
3. **Target bracket** (1–5, per `commander-rules-reference.md`'s Bracket system) — agreed with the table this deck will actually play at, since this drives how many Game Changers / fast mana / tutors / infinite combos are appropriate.
4. **Budget**, if any — recorded only as context for a real-world buy list, *not* as a constraint on the 99. This agent builds proxy-first: a card's dollar price is never a reason to cut it, pass it over, or pick a weaker card instead (same principle as ownership — see Step 3, question 5).
5. **Deck speed, table role, and inevitability** — three linked reads that set the curve, land count, sweeper count, and how many win conditions to run:
   - **Speed axis** (orthogonal to the archetype in item 2): is this deck *aggro* (a real clock — aims to end games by a target turn, low curve, few reactive cards), *control* (survives and wins late off card-advantage engines, runs sweepers and few win conditions), or *midrange* (efficient cards that both pressure and defend, flips role by game state)? An aristocrats, tokens, or reanimator deck can be any of the three — name which.
   - **Role is held per opponent.** "Who's the beatdown?" is answered separately against each opponent and shifts as players are eliminated; misreading it (durdling when you're the aggressor, racing when you're not) loses games. The deck knows its *default* role; the pilot reassesses in-game — see `in-game-play.md`.
   - **Inevitability check:** if the game goes long and nothing is disrupted, does *this* deck win at a typical table? If yes, it can run few win conditions and lean on interaction plus a protected engine. If no, it needs a real clock and a way to end the game before the table's grindiest deck takes over. Commander sources of inevitability: repeatable draw/tutor engines, recursion loops, scalable mana sinks, resilient threats (planeswalkers, creature-lands, enchantment win conditions); lifegain only against a burn-light table.

## Step 2 — Card quota guidelines (100-card deck, adjust for archetype)

These are starting ratios for the categories below the lands row, not hard rules — a combo deck needs more tutors and less removal than a value deck, a stax deck runs less card draw than a grindy one, etc. Say explicitly when you're deviating from one of those and why.

**Land count is not one of those flexible ratios — it is a hard requirement.** Build every deck with **exactly 35 lands. No more, no less, no stated-exception carve-out.** A mana-hungry finisher, a top-heavy curve, or a desire for insurance/redundancy on a land effect are reasons to reach for the Ramp row instead (rocks, dorks, rituals, doublers, mana sinks) — never a reason to run a 36th or 34th land. If a land add would push the count past 35, something else in the land base comes out in the same edit; the count is checked and held at exactly 35 after every single land-related change, not just when a land-count pass is explicitly requested.

| Category | Typical count | Notes |
|---|---|---|
| Lands | 35 (exact) | Hard requirement, not a range — every deck runs exactly 35 lands regardless of curve, archetype, or how mana-hungry the finisher is. Need more color fixing, ramp, or mana-sink capacity than 35 lands alone provide? Add it in the Ramp row below (rocks/dorks/rituals/doublers), not as extra lands. A land-based effect worth having twice (a redundant utility land, backup for another land's ability) still has to swap for an existing land, not add past 35. |
| Ramp (mana rocks/dorks/ramp spells) | 8–12 | Include in the land-count trade-off above. |
| Card draw / advantage | 8–12 | Recurring advantage engines count double toward "enough." |
| Removal (spot + board wipes) | 8–10 | In multiplayer a board wipe answers three players' boards with one card — most non-aggro decks want **3–5** wraths, not 1–3. For spot removal, favor instant-speed and modal / 2-for-1 effects: a 1-for-1 sorcery trades down against three opponents. |
| Protection / interaction (counterspells, hexproof effects) | 3–6 | More at higher brackets. **When the commander itself is the engine** — the deck can't realistically win without it resolving and staying on the battlefield — raise this to **6–8 distinct protection effects** across multiple types (see Strong-inclusion signals). Recasting from the command zone is a fallback, not protection: each recast costs {2} more and eventually you can't rebuild through it. |
| Synergy / payoff pieces | remainder | Everything that executes the actual game plan. |

**When filling a quota slot, prefer a card that counts toward two or more of these categories at once over an equally-powered single-purpose card** — a removal spell that also proliferates, a creature that ramps and blocks, a draw spell with real commander-specific synergy on top, etc. A card that does double duty is a more efficient use of the one slot it occupies, which is itself a legitimate answer to Step 3's opportunity-cost question. Weight commander-specific synergy heavily in this comparison — a card that's merely generically good is worth less than one that's generically fine *and* meaningfully better because of what this specific commander/game plan does.

**Multiplayer card economy.** You begin every game outnumbered three-to-one on cards, so a pure 1-for-1 is card-negative in effect. Prefer cards that replace themselves or two-for-one (modal removal, ETB-value creatures, board wipes), and treat recurring advantage engines as the backbone of the deck, not a luxury — this is why the card-draw row counts them double.

## Step 3 — Evaluate a candidate card against 5 questions

A card needs to clear these together, not pass just one — fitting the deck's theme doesn't excuse a bad mana-cost-to-value trade-off, and raw power doesn't excuse not fitting the plan. See `community-resources.md`'s "Deckbuilding theory & card evaluation" section for sourced methodology behind questions 2 and 4.

1. **Does it advance the game plan?** If it's just "a good card" but doesn't fit the archetype, it's a cut candidate even if powerful — Commander rewards coherence. Fitting the theme is necessary, not sufficient — see 2.
2. **Is it worth its mana cost on its own terms, in this deck?** Rate = effect delivered ÷ mana invested, judged against this deck's actual curve and speed. A card that complements the theme but underperforms its cost relative to what else is available at that cost is still a weak include — "on theme" doesn't waive this.
3. **Does it do too little on its own?** Cards that only work with 2+ other specific cards in play are weak general inclusions on their own merits (see question 2) — fine in small numbers, risky as the deck's backbone unless the deck *is* a combo deck. This is a standalone-value question, not a combo-ban question: `house-rules.md`'s infinite-combo prohibition restricts how the deck is *played* (don't chain the loop in an actual game), not which cards may be in the 99 — a card isn't cut just because it can combine with another specific card to form an infinite loop, unless that card is itself named on the Custom ban list. Only treat a combo as disqualifying if it *is* the deck's actual win condition, not an incidental interaction between two otherwise fine inclusions.
4. **What's the opportunity cost against the actual alternatives?** A slot given to this card is a slot not given to every other card that could fill it. Name at least one real alternative for the slot and state explicitly why this card wins the comparison (better rate, better curve fit, higher floor/ceiling for this deck specifically) — don't evaluate a card in isolation and call it done.
5. **Ownership and price are informational, not selection criteria.** Pick the best card on questions 1–4 alone. Separately, annotate whether the player owns it (`raw/manabox_Collection.csv`) and its rough price, so a buy list can be produced — but never cut, downgrade, or pass over a card because it's unowned or expensive, and never default to a weaker card because it's owned or cheaper. The build is theoretical / proxy-first; real-world acquisition is a separate downstream question.

**On community synergy data specifically**: EDHREC's synergy scores come from the wider Commander population, which plays cards `house-rules.md` bans for this table (fast mana beyond Sol Ring, stax, infinite combos, free counterspells, and more). A high synergy score doesn't automatically transfer here — before recommending a card on synergy strength, check whether the reason behind that score depends on an interaction this pod doesn't allow, and discount it if so.

**Document the answer, per card.** A finalized or updated decklist in the deck's `wiki/<topic>.md` page isn't a bare card-name list — each card carries a one-line justification (which of the above it wins on) and names what it actually synergizes with in this deck, not just "fits the theme." See `wiki-structure.md` for the exact format. This is what lets a later session reconsider a specific include/cut on real reasoning instead of re-deriving it from scratch.

**A card cut in an earlier revision is not permanently disqualified.** Re-run these 5 questions against it fresh when it comes up again rather than treating the old cut as settled — the original reasoning was scoped to the deck and the role being filled *at that time* (e.g. "too soft as the deck's only fuel source") and may not hold once the build or the specific slot being filled has changed (e.g. it's now a *second* piece backing up an existing anchor, rather than the sole engine). Document the new reasoning rather than just re-adding the card silently.

## Common rejection patterns (catch these before finalizing)

Recurring reasons a card gets cut in review — checking for these directly tends to catch problems faster than only running the Step 3 questions in the abstract:

- **Narrow/meta-specific tech without a stated reason.** A card whose value depends on a specific opposing strategy (tribal hate, graveyard hate, artifact hate) is a weak default include — only run it if there's an actual reason tied to this pod's known tendencies, not "just in case." Pod knowledge *is* that reason: if the recurring table has a graveyard, artifact, or tribal deck, the matching hate graduates from weak-default to correct maindeck. Absent specific knowledge of the pod it stays speculative — see the Table politics section and `in-game-play.md`'s metagame note.
- **Weak effect in a category that has better options.** "It's removal/draw/ramp, the deck needs some" isn't sufficient on its own — compare it against the other real candidates in that category at similar cost (Step 3, question 4); a small or conditional effect loses to a cleaner one even if both technically qualify.
- **Payoff type doesn't match the actual win condition.** A card that rewards combat damage/attacking is dead weight in a deck whose plan is sacrifice, drain, control, or an alt-wincon that doesn't route through connecting in combat — check the payoff's trigger against Step 1's stated game plan, not just its color or type.
- **A fixed single-mode card loses to a flexible one at equal cost.** Between two cards at the same mana cost, one offering a choice of modes (e.g., ramp *or* draw *or* a body) is usually the better include over a fixed single-effect card, all else equal — flexibility adapts to whatever the game state actually needs.
- **The deck's critical engine has no protection.** If the whole plan routes through one card (a single draw engine, the commander itself), size the protection suite (redirect effects, hexproof/ward, indestructible) to that dependency, not to a flat baseline — see the Synergy checklist below and Step 2's protection quota. When that dependency is the commander itself, "sized to the dependency" means **6–8 distinct effects across multiple types** — see the "Size engine protection…" signal below.
- **Redundant with something the commander already does for free.** Check a candidate against the commander's own printed abilities before checking it against the rest of the 99 — a card that grants an effect the commander already provides to your whole board (e.g., "creatures you control have wither") is purely wasted, a cleaner disqualifier than ordinary in-deck redundancy.
- **A synergy piece whose ability needs an existing board resource is only as good as how reliably that resource is actually present when you'd use it.** "Proliferate" with no counters in play does nothing — don't credit a card for synergy the deck only theoretically enables elsewhere; check the realistic sequencing (what's usually already in play by the turn you'd use it). If the missing resource is something the deck could reliably manufacture (see "commander fuel" under Strong-inclusion signals), the fix may be adding that enabler rather than cutting the piece.
- **Judge a card by its total cumulative cost to reach its useful payoff, not its printed casting cost.** Level-up, equip-stacking, and similar pay-more-over-time mechanics can turn an apparently cheap card into one of the most mana-hungry cards in the deck — compare that real total against what the same mana buys elsewhere (Step 3, question 4), not against the number in the mana-cost box.
- **All answers, no plan.** A deck that's mostly removal and counterspells with a thin, slow win condition tends to lose in multiplayer: answers are card-disadvantageous (they whiff, trade, or mismatch) and you can't 1-for-1 three opponents, while "there are no wrong threats." Every deck needs a proactive plan it advances on its own turns; interaction buys time for that plan, it isn't the plan (Step 1, item 5's inevitability check is the same question from the other side).

## Strong-inclusion signals

The flip side of the rejection patterns above — traits that make a card worth including even when it doesn't look obviously powerful on its own:

- **A symmetric or opponent-helping card is a strong include only when you hold a lever to break the symmetry** — you use the effect better by design, you dodge its downside, you control its timing, or it locks a lead once you're ahead. The fodder/token-payoff and snow-covered-basics bullets below are both instances of this. Without one of those four levers, a "symmetric" card is just a good card for your opponents too.
- **A fodder/token effect is judged by what the deck does with the tokens next, not who "gets" them on paper.** A card that seems to help opponents (giving them a creature, or a symmetric effect that also triggers off their permanents) can be a strong include if the deck's actual payoff converts those tokens into a one-sided advantage — e.g., killing low-toughness fodder for card draw or drain in a mass-toughness-reduction deck. Read the whole chain the card sets up, not just its first line.
- **A kicker/conditional bonus the deck can't fully enable isn't a reason to cut a card whose baseline mode already clears the bar.** Evaluate what the card actually delivers given this deck's real build, not its full advertised ceiling — an unused upside is a bonus, not a requirement to unlock before the card is worth including.
- **A repeatable value engine is also protection, even with no protection text on it.** It forces a dilemma: it goes unanswered and produces steady value, or an opponent spends real interaction on a noncreature permanent instead of on your actual threats. Weigh that implicit tax alongside the card's face-value output when comparing it to a one-shot alternative at the same cost.
- **Size engine protection to how hard the deck leans on the engine.** If the whole plan routes through one permanent — the commander, a sole draw or combo engine — run **6–8 distinct protection effects**, not the baseline 3–6. Treat "protection" as a toolbox, not just hexproof: (1) evasion of targeting (hexproof / ward / shroud); (2) indestructible / protection / totem armor — but this does nothing against −X/−X, exile, sacrifice, or bounce; (3) redirect / misdirection; (4) blink / phase-out, to dodge and reset; (5) cheap recursion, so removal is a tempo hit rather than a game-ender; (6) a counterspell *held* for the removal instead of spent proactively; (7) for a deck slow enough to be raced, fog / damage prevention / lifegain so you don't die before the engine matters. Diversify across those types — three hexproof grants all fail to the same edict or wrath, whereas a redirect plus an indestructible plus a recursion each answer a different kind of removal. Know your colour's slice of the toolbox: mono-black leans on redirection, recursion, a few creature-only counters, and fogs — it doesn't get the white/blue hexproof-and-permission suite, so it needs more redundancy in the tools it does have.
- **A ramp or payoff piece that scales with a resource this deck's own build already maximizes (e.g. basic-land count in a mono-color deck) outperforms an equally-costed piece that doesn't** — the scaling is free, since the deck is already doing the work that powers it. Same idea as Step 2's multi-category preference, applied specifically to scaling effects.
- **Freeroll the specialized version of an equivalent piece — the Rule of Low-Opportunity Subtypes.** When a slot lets you swap a generic game piece for a more specific one at zero or near-zero opportunity cost — no extra mana, no tempo loss (still enters untapped, costs the same, fixes the same), no consistency hit — take the specialized version whenever its subtype, name, or characteristic could ever unlock synergy or asymmetry. The upside is a freeroll; it can only break your way. The gate is that the swap must genuinely be costless: snow-covered basics for plain basics qualify (identical function, plus snow-matters and Extraplanar Lens upside); a tapland for an untapped land does **not** (real tempo cost); an artifact mana rock over a non-artifact equivalent qualifies *only* in a deck that runs artifact payoffs. Sibling of Step 2's multi-category preference, and a companion to the scaling-effects signal above.
- **A utility land folds a spell-level effect onto a land slot — within the mana base's tolerance.** Targeted land destruction, graveyard hate, creature or land recursion, a repeatable mana sink, a land-ability copier, a counter / proliferate source — putting one of these on a land lets the deck run an effect it couldn't spare a whole card on, a real instance of Step 2's multi-category preference. The cost is paid in the mana base (Step 5): many enter tapped, add only colourless, or ping you, so each is a partial or non-source. Cap the count against the deck's *tightest* coloured requirement — a deck with {B}{B}{B} or {G}{G} costs absorbs far fewer than an even two-colour curve — and past that point each one traded for a coloured source is a consistency cut, not a freeroll. Single-target land destruction specifically is legal under a typical "no mass land destruction" house rule and is the clean answer to an opponent's engine-land, but it still needs a target worth a card, so it stays a weak default without a pod reason.
- **If the commander's core engine consumes a resource only opponents can supply — "commander fuel."** Some commanders do nothing until an opponent provides the input their ability eats: creatures to kill or that die, attackers to punish, spells to counter, artifacts to blow up. Against a table that doesn't supply it, the commander is a blank. Such a deck needs a small dedicated package that manufactures the resource itself — even at the cost of handing opponents material (giving each opponent a creature, running a symmetric token maker). A repeatable, always-on source (a land, a cheap enchantment/artifact engine) is worth more than a one-shot here, because the failure case is a whole game with no input. Size it explicitly (~3–5 slots) and name what each piece fuels. This is the "read the whole chain, not who gets the token" logic of the fodder/token bullet above, applied to the commander's own dependency.
- **Flexibility raises the floor.** A modal spell, an X-cost / mana-sink creature, or an instant is worth taking over a narrowly stronger card when it's rarely dead in an imperfect draw, the raw-power gap to the specialist is small, and it answers more than one common problem. Mana sinks earn extra credit in Commander specifically: the late game floods, so a scalable outlet turns dead land draws into advantage — which is also a source of the inevitability from Step 1, item 5.
- **Trigger frequency is part of a card's rate, not just its printed effect.** Between two cards of comparable power and cost, the one whose ability can trigger multiple times over a game (repeatable, or off a recurring event such as any creature entering) outweighs one that only triggers once (a single ETB, a one-shot effect) — more chances to matter, more resilience to being answered once, more compounding value in a long Commander game. This is the general form of the Commander Fuel signal's "a repeatable, always-on source is worth more than a one-shot" — apply it outside the fuel case too (draw, removal, token generation, protection).

## Step 4 — Power-level calibration

Tie recommendations back to the target bracket:

- **Brackets 1–2**: avoid Game Changers entirely, avoid fast infinite combos, favor thematic/synergy cards over raw efficiency, don't over-optimize the mana base with high-power fixing (Game-Changer-tier fast lands, the strongest utility lands) unless the player wants that — a power / play-feel call, not a price one.
- **Bracket 3**: up to 3 Game Changers is normal; still generally avoid a deck whose whole plan is a 2-card infinite combo that ends the game with no interaction window.
- **Brackets 4–5**: optimize freely; consult live card data aggressively rather than relying on this file's general guidance, since the metagame at this level moves fast.

## Step 5 — Mana base sanity check

- Color pip count across the deck (not just card count) is the better guide to how many sources of each color you need — a deck with double-pip commitments in one color needs more sources of that color than an even 3-color split.
- **Sources per pip (Karsten math — live-verifiable, see `community-resources.md`).** As a rule of thumb for a 99-card deck at ~90% on-curve consistency: roughly **20–22 sources for a single colored pip**, **28–30 for a double pip**; fewer is acceptable if "a turn late, most games" is fine for that card. Count every color-producing land, rock, dork, and universal fixer (Command Tower, Arcane Signet, signets/talismans, Fellwar Stone) as a source; conditional or fetch-only-in-color sources count for less. Colorless-only utility lands are *non-sources* — add them last, and cap them against the deck's tightest color requirement. This sits in tension with Step 2's hard 35-land requirement; close the gap with rocks/dorks and universal fixers rather than more lands, since the land count itself cannot move.
- Untapped, colorless-fixing lands (e.g. basics, fetches, duals) are worth more early; taplands are worth less in aggressive/low-curve decks.
- Optionally note when a mana base leans on cards the player doesn't own yet vs. is buildable today from the collection — an annotation for a buy list, not a reason to change the recommendation (see Step 3, question 5).
- If a specific color is starved despite an adequate pip-to-land ratio, prefer mana-fixing/doubling tools (in-color signets/talismans, filter lands, snow-typed basics paired with a snow payoff like Extraplanar Lens) over adding more lands of that color — land count cannot move at all (Step 2's hard 35), so a color problem has to be solved by what's already in the 35, or by nonland fixing.
- **A 36th (or 34th) land never earns its slot, because that slot doesn't exist.** Once the mana base clears the Karsten floor above for the deck's actual pip requirements, an additional land beyond 35 would buy only a small, calculable reduction in flood/screw risk anyway — moving from 36 to 35 lands changes the odds of a land-heavy or land-light opening hand by only a couple of percentage points — so the math agrees with the hard rule, it isn't just overridden by it. A card whose case for inclusion is "worth running one over quota" has already lost; it goes in Ramp instead, or it doesn't make the 99. When a land needs to come out to make room for a different land (a new utility land, backup redundancy for an existing effect), cut the most conditional/narrowest-value land currently in the 35 first (a situational utility land, a life-cost source, an excess basic) before touching pip-critical sources or engine lands (Step 3's card-evaluation logic, applied to the land base itself) — never leave the count sitting above 35 in the meantime.
- **Mono-color decks: default to snow-covered basics, and to Extraplanar Lens on top.** Snow basics function identically to plain basics, so running them is a freeroll (see the Rule of Low-Opportunity Subtypes under Strong-inclusion signals) — do it regardless of whether anything else in the deck cares. Extraplanar Lens then imprints one and doubles the mana of every land *with the same name*, so on an all-snow base only your basics benefit and opponents on plain basics get nothing — the one-sided version of an effect that's normally symmetric. Treat Lens as a strong default, subject to the usual opportunity-cost check: it's an artifact slot and a removal target, does nothing until drawn, and a snow-hate or heavy-artifact-removal meta makes it unreliable; an opponent also on same-name snow basics would share the doubling. Its dollar price is not part of that check.

## Synergy checklist (for evaluating a whole deck, not just one card)

- Is there a clear A-to-B-to-win path, or is it a pile of good-but-disconnected cards?
- Are there redundant effects for the deck's most important effect (e.g. multiple sac outlets in an aristocrats deck), or direct protection for it (redirect effects, hexproof/ward, indestructible) when redundancy isn't practical for a genuinely unique engine piece — so one removed or countered piece doesn't blank the plan? If that unique piece is the commander itself, hold this to the 6–8-distinct-effects standard in the "Size engine protection…" signal, not a token one or two.
- Does the deck have a plan against removal-heavy or counterspell-heavy tables, or is it fully reliant on one resolving spell?
- Is there a way to interact with what opponents are doing, or is this a fully solitaire deck (fine for casual, risky at higher brackets)?
- If the commander's engine only functions when opponents supply an input (creatures to kill, attackers, spells, artifacts), what guarantees that input against an opponent who doesn't provide it — is there a "commander fuel" package (Strong-inclusion signals), and is it repeatable rather than one-shot?

## Table politics & play strategy

Commander is multiplayer and social by design (`commander-rules-reference.md`) — a deck's *deck-building* strengths and its *political* exposure aren't the same thing, and both matter for "how good is this deck" beyond raw power level.

- **Threat assessment**: the table generally targets whoever looks closest to winning or hardest to interact with, not whoever is "strongest" on paper. A deck that telegraphs its win early (a big flashy commander, an obvious combo piece in play) draws removal a low-key deck doesn't — factor this into card evaluation, not just power.
- **Deal-making**: temporary alliances ("don't attack me this turn, I'll not counter your next spell") are normal play, not a house rule — but they're non-binding; advise honoring the spirit of a deal you made unless the game state changed enough to justify breaking it, since a table that stops trusting a player's word changes how everyone plays against them going forward, across games.
- **Kingmaker/spite plays**: when a player is eliminated or clearly can't win, how they spend their last actions (helping decide who *does* win) is a real political lever, not just "well they're out anyway" — worth factoring into how a deck plays if it tends to make enemies along the way.
- **Archetype-specific exposure**:
  - *Group hug / politics* decks buy goodwill but can accidentally accelerate an opponent to a win — pair with some way to close out the game or interact late, not just generosity.
  - *Stax / resource denial* decks draw disproportionate table heat — worth discussing with the player up front whether that's an accepted deck for their table (see `house-rules.md` for their group's power-level agreement) rather than discovering it mid-game.
  - *Voltron* (single-creature beatdown) is an obvious, concentrated threat — protection density matters as much as raw power, since the whole plan dies to one removal spell resolving.
  - *Combo* decks read as either "impressive" or "unfun" depending on the table's stated bracket/expectations — calibrate against the target bracket from Step 1, not just whether the combo is legal.

For deeper reading beyond this framework-level summary, live-fetch Commander's Herald's politics/table-dynamics content per `community-resources.md` rather than expecting this file to cover it exhaustively.
